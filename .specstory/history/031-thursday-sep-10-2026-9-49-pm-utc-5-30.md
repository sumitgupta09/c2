Spec Kit Ka Flow (Kaam Kaise Karta Hai)
specify init (Setup)
Aap terminal me command chalakar project initialize karte hain.
Yeh AI agent (jaise Copilot, Cursor ya Claude Code) ke liye zaruri files aur rules set kar deta hai.
.constitution.md (Kanoon / Rules)
Aap AI ke liye strict kanoon tay karte hain (jaise: "React aur Tailwind CSS hi use karna", ya "Code me security sabse pehle honi chahiye").
AI is kanoon ko tod nahi sakta.
/specify (Requirements / Idea)
Aap AI ko batate hain ki kya banana hai (lekin kaise banana hai yeh nahi).
For example: "Mujhe ek podcast ki website chahiye jisme light/dark mode ho." AI iska ek proper document bana deta hai.
/plan (Technical Architecture)
AI aapke idea aur .constitution.md ke rules ko mila kar ek technical plan banata hai.
Yeh decide karta hai ki kon-kon si libraries, files, aur components use honge.
/tasks (To-Do List)
AI technical plan ko chhote-chhote steps (tasks) me tod deta hai.
Chhote steps hone ki wajah se AI confuse nahi hota aur galat code nahi likhta.
/implement (Coding Phase)
AI ek-ek task ko pakad kar code likhna shuru karta hai aur aapki website/app tayar ho jaati hai.
Iska Main Fayda Kya Hai?
No "Vibe Coding": Jab hum AI ko direct bolte hain "meri website bana do", toh woh apne mann se kuch bhi bana deta hai aur bad me bugs aate hain. Spec Kit se AI step-by-step aur ek systematic tarike se kaam karta hai.
Control Aapke Hath Me: Har step par ek Markdown file (.md) banti hai, jise aap edit karke AI ko control kar sakte hain. ye snb bhi kia tha na  use ?
